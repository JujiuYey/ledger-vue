# Labels and i18n

Zero hardcoded strings: everything user-visible flows through the `labels` object (`DataTableLabels`). English defaults ship in the package; a complete Simplified-Chinese preset ships from the `./locales` subpath. Chrome glyphs follow the same rule through the `icons` registry (Vue components, `icons.ts` defaults) — never render a glyph component directly.

## Configuring

App-wide, the Vue-native way — there is no host theme to hang `defaultProps` on and no library-side locale provider, so the application owns the switch: a language provide plus a `labels` computed, bound with `:labels` on every table and compound (the playground's `src/i18n.ts` is the reference):

```ts
// i18n.ts
import type { ComputedRef, InjectionKey, ShallowRef } from "vue";
import { computed, inject, provide, ref } from "vue";

import { defaultLabels, type DataTableLabels } from "@jujiuyey/ledger-vue";
import { zhCN } from "@jujiuyey/ledger-vue/locales";

export type Lang = "en" | "zh";

const lang = ref<Lang>("en");

const LanguageKey: InjectionKey<{ lang: ShallowRef<Lang>; setLang: (lang: Lang) => void }> = Symbol("Language");

export function provideLanguage(): void {
  provide(LanguageKey, { lang, setLang: next => (lang.value = next) });
}

export function useLang(): { lang: ShallowRef<Lang>; setLang: (lang: Lang) => void } {
  return inject(LanguageKey, { lang, setLang: next => (lang.value = next) });
}

// The app-wide labels, one per language — a computed, so every `:labels` binding flips with it.
export function useLangLabels(): ComputedRef<DataTableLabels> {
  return computed(() => (lang.value === "zh" ? zhCN : defaultLabels));
}
```

```vue
<script setup lang="ts">
import { DataTable } from "@jujiuyey/ledger-vue";
import { useLangLabels } from "../i18n";

const labels = useLangLabels();
</script>

<template>
  <DataTable :data="people" :columns="columns" :labels="labels" … />
</template>
```

The table resolves `labels` in a `computed`, so a reactive source — the computed above — re-renders the copy in place when the language flips.

Per instance, pass a partial — anything omitted falls back to the defaults:

```vue
<DataTable :labels="{ empty: '还没有任何记录', searchPlaceholder: '搜索成员…' }" … />
```

`resolveLabels` is exported for the same job outside the component: `resolveLabels(partial)` returns a complete `DataTableLabels` — the exact merge the table itself runs over `defaultLabels`.

The standalone compound components (`DataTableSearch`, `DataTableColumnsPanel`, `DataTablePagination`, `DataTableSelectionBar` — named imports; dot notation is not resolvable in Vue templates) render outside the table tree, so each takes its own `labels` prop; the app-wide provide above feeds them the same way. Search, the columns panel, and the selection bar resolve their `labels` once at setup — a runtime language flip remounts them (`:key="lang"`, the playground pattern); `DataTablePagination` re-resolves on every render. The built-in pagination bar inherits the table's `labels`.

## The catalog

Eight entries are functions (they compose a number, a column name, or a row name into the copy); everything else is a string.

| Group | Key | English default |
| --- | --- | --- |
| Pagination | `paginationSummary(from, to, total)` | `` `${from}–${to} of ${total}` `` |
| | `rowsPerPage` | `Rows per page` |
| Selection | `selectAllRows` | `Select all rows` |
| | `selectRow` | `Select row` |
| | `selectedCount(count)` | `` `${count} selected` `` |
| | `clearSelection` | `Clear selection` |
| Expansion | `expandRow` / `collapseRow` | `Expand row` / `Collapse row` |
| | `expandAll` / `collapseAll` | `Expand all rows` / `Collapse all rows` |
| Active row | `rowNavigation` | `Table rows — use the arrow keys to move between rows` — describes the focus stop while `enableActiveRow` is on |
| | `currentRow(row, index, count)` | `` `${row}, row ${index} of ${count}` `` — announced politely when the current row changes |
| Columns panel | `columnsPanel` | `Columns` |
| | `resetColumns` | `Reset` |
| | `pinStart` / `pinEnd` / `unpin` | `Pin to start` / `Pin to end` / `Unpin` — logical positions (left/right in LTR, mirrored in RTL) |
| | `pinnedStart` / `pinnedEnd` | `Pinned start` / `Pinned end` — captions over the panel's pinned zones |
| | `groupByColumn` / `ungroupColumn` | `Group by this column` / `Ungroup` |
| | `columnWidth` | `Width` |
| | `columnWidthAuto` | `Auto` — the width placeholder for a column that declares no `size` |
| Column interactions | `resizeColumn` | `Drag to resize; double-click to fit content` |
| | `reorderColumn` | `Drag to reorder column` |
| Filters | `filterColumn(column)` / `clearFilter` | `Filter {column}` / `Clear filter` — names the funnel and the control inside it |
| | `filterPlaceholder` | `Filter…` |
| | `filterRangeMin` / `filterRangeMax` | `Min` / `Max` |
| Search | `searchPlaceholder` | `Search…` |
| States | `loading` / `empty` / `noResults` | `Loading` / `No data` / `No matching records` |
| | `loadingMore` / `loadMoreError` | `Loading more` / `Couldn't load more rows` |
| | `error` / `retry` | `Couldn't load data` / `Retry` |
| Editing | `editColumn(column)` / `editPending` | `Edit {column}` / `Saving` — `editColumn` names each inline editor |
| Row ordering | `reorderRow` | `Drag to reorder row` — every handle's name and tooltip |
| | `rowOrderingUnavailable` | `Clear sorting, filters, and grouping to reorder rows` — the disabled handles' tooltip |
| | `rowReorderLifted(row)` | `{row} lifted — use the arrow keys to move, space to drop, escape to cancel` |
| | `rowReorderTarget(row, side)` | `Before {row}` / `After {row}` — announced as the drop target changes |
| | `rowReorderDropped(row)` / `rowReorderCanceled` | `{row} dropped` / `Reorder canceled` |

Most of these are accessibility labels (`aria-label`s on icon-only controls) — a translated table is also a screen-reader-correct table.

## Writing a locale

A locale is just a complete `DataTableLabels` value; `defaultLabels` is exported for spreading:

```ts
import { defaultLabels, type DataTableLabels } from "@jujiuyey/ledger-vue";

export const deDE: DataTableLabels = {
  ...defaultLabels,
  paginationSummary: (from, to, total) => `${from}–${to} von ${total}`,
  rowsPerPage: "Zeilen pro Seite",
  empty: "Keine Daten"
  // …
};
```

Contributions of complete locales belong in `src/locales.ts` (published under `./locales`), following the `zhCN` shape.
